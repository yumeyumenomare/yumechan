# 제작용 임시 자료

`backdata/`는 스킬을 만들거나 고칠 때 참고할 입력 자료(예: 엑셀 구조 확인용 원자료, 기존 스크립트)를 임시로 두는 폴더다. 이 안내 파일 외의 내용은 Git 배포 대상에서 제외하며, 완성된 스킬은 이 폴더에 의존하지 않는다.

- 실제 사용에 필요한 규칙·구조 설명만 정리해 해당 스킬의 `references/`, `assets/`에 포함한다.
- 원자료나 결과 파일을 원본 보존이라는 이유로 스킬 폴더에 복사하지 않는다.
- 이 폴더를 비워도 배포 파일과 작업 입력만으로 스킬을 이해·적용할 수 있어야 한다.

작성·검증 기준은 [유지보수 안내](../skills/MAINTENANCE.md)를 따른다.
