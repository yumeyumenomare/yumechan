# PSY 검정과 임계값 방법 비교

## 목적과 범위

연구 질문은 **같은 GSADF/BSADF 통계량에 서로 다른 임계값 방법을 적용하면 거품 판정이 얼마나 달라지는가**다. 따라서 이 스킬의 불변 조건은 하나다. **통계량은 고정하고 임계값 방법만 바꾼다.** 방법 간 비교가 공정하려면 같은 계열·표본·최소창을 써야 한다.

- **적용:** 통계량 계산, 세 방법의 임계값 산출, 기각 판정, 시점 추정(date-stamping), 강건성 재실행(시차, SA/NSA, D2).
- **비적용:** 자료 구성은 `kb-housing-data-prep`, 결과표·그림은 `bubble-results-reporting`이 맡는다. 코드를 쓸 때는 `r-readable-analysis-code`를 함께 적용한다.

## 고정 사양

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 검정 | PSY(2015) GSADF는 요약 판정, BSADF는 시점 추정 | |
| 시차 k | 주분석 1, 강건성 4. 고정 시차 | PSY(2015) Table 2에서 BIC 시차 선택은 명목 5%에서 실제 크기가 최대 0.198까지 왜곡된다. 정보기준 선택을 쓰지 않는다 |
| 최소창 | PSY 규칙 r0 = 0.01 + 1.8/√T, `psy_minw(T)` | 통계량과 세 임계값 모두 같은 값 |
| 시드 | 42 | 모든 시뮬레이션·부트스트랩 |
| 구현 | exuber 패키지 함수만 사용 | 자체 부트스트랩 구현은 검증 부담이 크고 재현·방어가 어렵다 |
| 유의수준 | 95%로 판정, 90%·99% 함께 보고 | |
| 반복 수 | `cfg$n_rep`. 잠정 MC 999 / 부트스트랩 199 | 최종값은 사용자가 확정한다. NA이면 최종 실행을 하지 않는다 |
| 시점 추정 최소 지속기간 | `cfg$min_duration` | NA이면 시점 추정 전에 사용자에게 확인한다. 후보는 `psy_ds(T)` = round(log T), T=490이면 6개월 |

사양값은 `config.R`에서 읽는다. 이 표의 값을 바꾸면 `coding/r-readable-analysis-code/assets/config-template.R`도 함께 고친다.

## 방법별 exuber 함수

exuber 1.1.0 기준이다. 인자·반환 구조의 상세는 [exuber 함수 사양](references/exuber-api.md)을 읽는다. 설치된 버전이 다르면 먼저 `packageVersion("exuber")`와 `args()`로 확인한다.

| 단계 | 함수 호출 | 핵심 |
| --- | --- | --- |
| 통계량 | `radf(data, minw, lag = k)` | 기본값 `lag = 0L`이므로 반드시 k를 넘긴다 |
| MC | `radf_mc_cv(n = T, minw, nrep, seed)` | 자료가 아니라 표본 크기만 받는다. 같은 T의 계열은 같은 MC 임계값을 공유한다 |
| WB (HLST 2016) | `radf_wb_cv(data, minw, nboot, seed)` | 시차 인자가 없다. 부트스트랩 회귀에 시차를 넣지 않는 것이 원 논문 사양이며 패키지 오류가 아니다 |
| WB2020 요약 판정 | `radf_wb_cv2(data, minw, nboot, adflag = k, type = "fixed", tb = NULL, seed)` | GSADF 판정에는 `tb`를 주지 않는다 |
| WB2020 시점 추정 | 위와 같되 `tb = ps_tb(T, "monthly", size = cfg$wb2_tb_size)`, 값은 2 | 2년(24개월) 구간의 다중검정 크기를 통제한다. BSADF 임계값이 시간에 대해 상수가 된다 |
| 판정 | `diagnostics(stat, cv)` | |
| 시점 | `datestamp(stat, cv, min_duration)` | |

## 반드시 지킬 제약

1. **tb 결과로 요약 판정하지 않는다.** `tb`를 준 `radf_wb_cv2()`는 길이 tb의 모의 표본으로 분위수를 구하므로, 그 GSADF 임계값은 전체 표본 판정용이 아니다. 전체 표본 판정에 쓰면 임계값이 크게 낮아져(약 1.1~1.6) 거의 모든 지역이 유의하게 나온다. tb 결과는 BSADF 시점 추정에만 쓴다.
2. **tb에 24를 직접 넣지 않는다.** `ps_tb(T, "monthly", 2)`는 `minw + 24 − 1`을 돌려준다(T=490이면 44 + 23 = 67). 24는 크기를 통제할 구간 길이이고 `tb` 인자는 모의 표본 크기다. 실행 시 `ps_tb()` 값을 출력하고 기록한다.
3. **표본 블록별로 따로 실행한다.** `main`(1986.01), `d2`(1987.01), `supp`(1996.01)는 T와 최소창이 다르다. `radf()`는 NA를 받지 않으므로 시작월이 다른 계열을 한 행렬에 섞지 않는다.
4. **최소창을 명시한다.** 블록마다 `minw <- psy_minw(T)`를 한 번 계산해 통계량과 모든 임계값 호출에 같은 값을 넘긴다. 함수 기본값(`minw = NULL`)에 맡기지 않는다. 예: T=490이면 44, T=370이면 38.
5. **재현 설정을 고정한다.** 스크립트 시작에서 `options(exuber.parallel = cfg$exuber_parallel, exuber.ncores = cfg$exuber_ncores)`를 설정하고 결과와 함께 기록한다. exuber 문서에 따르면 병렬 여부가 바뀌면 같은 시드라도 결과가 달라진다. 최종 결과는 한 설정으로 만든다.
6. **사양을 바꾸지 않는다.** 정보기준 시차(`type = "aic"/"bic"`), Rademacher 가중치(`dist_rad = TRUE`), 다른 최소창은 사용자가 강건성 분석으로 명시적으로 요청한 경우에만 쓰고, 결과 이름에 사양을 표시한다.
7. **결과를 저장해 재사용한다.** 부트스트랩 결과는 사양을 담은 이름의 `.rds`로 저장한다. 예: `cv_wb2_D1_SA_main_k1_nb199_s42.rds`. 같은 사양이면 저장된 파일을 읽고, 사양이 다르면 새로 계산한다.

## 작업 절차

1. **입력 확인:** `kb-housing-data-prep`이 만든 블록·변수·조정별 행렬을 읽는다. NA가 없고 블록 안의 T가 같은지 확인한다.
2. **블록 정보 출력:** 블록마다 T, 기간, `minw`, `ps_tb()` 값, 지역 목록을 출력한다.
3. **통계량:** `radf(data, minw, lag = k)`.
4. **임계값 네 가지:** MC, WB, WB2020(`tb` 없음), WB2020(`tb` 있음, 시점 추정용). 반복 수는 `cfg$run_mode`에 따라 잠정값 또는 최종값을 쓴다.
5. **판정:** 지역 × 방법마다 GSADF 통계량과 90·95·99% 임계값을 나란히 두고, 통계량이 95% 임계값보다 크면 단위근 귀무가설을 기각한다(폭발적 행태의 증거). MC, WB, WB2020(`tb` 없음) 세 방법을 비교한다.
6. **시점 추정:** BSADF 계열을 시점별 임계값과 비교한다. MC와 WB는 시간에 따라 변하는 임계값, WB2020은 `tb`를 준 상수 임계값을 쓴다. 최소 지속기간은 `cfg$min_duration`이다.
7. **저장:** 다음을 `outputs/`에 저장한다.
   - 판정표: `block, dep_var, adj, lag, region, method, stat, cv90, cv95, cv99, reject95`
   - 시점 추정 구간표: `region, method, start, end, duration`
   - BSADF 계열과 방법별 시점 임계값(그림용)
   - 사용 사양: T, `minw`, `tb`, 반복 수, 시드, exuber 버전과 병렬 설정

## 해석할 때

방법 간 결과 차이를 설명하거나 논문 방법론 절을 쓸 때는 [임계값 방법의 이론과 해석 근거](references/critical-value-decisions.md)를 읽는다. 핵심은 세 가지다.

- **MC**는 동분산 가정 아래의 분포라, 변동성이 비정상(volatility non-stationarity)인 자료에서 과대기각(over-rejection)한다.
- **WB**는 시간 순서대로 가중치를 곱해 이분산 패턴을 보존한다. 다만 이론적 결과는 SADF에서만 증명되었고 GSADF 확장은 저자들의 기대이므로 논문에 밝힌다.
- **WB2020**은 잔차를 무작위로 재추출하므로 부트스트랩 오차 분산이 시간에 대해 일정하다. 임계값 상승은 주로 다중검정 보정에서 오며, 이분산 강건성에서 오지 않는다.

## 결과물과 확인

- 블록마다 통계량과 모든 임계값에 같은 `minw`가 쓰였는가?
- 요약 판정에 `tb` 없는 WB2020 결과를 썼는가?
- 시차·반복 수·시드·병렬 설정이 결과 파일에 기록되었는가?
- 잠정 실행과 최종 실행의 결과가 섞이지 않았는가? (`run_mode`를 파일 이름에 포함)
- 방법별 유의 지역 수를 출력했는가? 결과가 이전 실행이나 예상과 다르면 사양을 바꿔 맞추지 않는다. 자료 발표본, 블록, `minw`, 시차, 반복 수의 차이를 먼저 점검하고 그대로 보고한다.
