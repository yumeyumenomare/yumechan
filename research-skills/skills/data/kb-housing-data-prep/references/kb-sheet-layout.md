# KB 월간 주택 시계열 시트 구조

이 문서는 2026.10 발표본의 `1.매매종합`, `5.전세종합`, `2.매매APT`, `6.전세APT` 시트를 기준으로 한다. 새 발표본에서는 아래 구조를 먼저 확인하고, 달라진 점이 있으면 이 문서를 갱신한다.

## 행 구성

| 행 | 내용 | 예 |
| --- | --- | --- |
| 1 | 지수 이름과 기준시점 | `주택매매가격 종합지수 ... (2026.01=100.0)` |
| 2 | 시도·시·권역 이름. 셀 안 줄바꿈 포함 | `서울\n특별시`, `강북\n14개구`, `수원시` |
| 3 | 구·군 이름. 상위 지역은 2행의 가장 가까운 왼쪽 값 | `강북구`, `분당구` |
| 4 | 영문 이름 | `Seoul`, `Bundang-gu` |
| 5~ | 월별 자료 | |

- 같은 지역이라도 시트마다 2행 표기가 다를 수 있다. 예: `1.매매종합`은 `서울\n특별시`, `5.전세종합`은 `서울특별시`. 줄바꿈과 공백을 지운 이름으로 비교한다.
- 3행이 비어 있는 열은 2행 이름이 곧 그 열의 지역이다. 3행에 값이 있는 열은 `2행 상위 이름>3행 이름`으로 식별한다.
- 4행 영문 이름에는 끝 공백이 섞여 있다(`Jung-gu `). 식별에는 2·3행 한글 이름을 쓴다.

## A열 날짜 표기

| 구간 | 1월 표기 | 2~12월 표기 | 엑셀 셀 형식 |
| --- | --- | --- | --- |
| 1986~1999 | `86.1` … `99.1` | `2` … `12` | 숫자 |
| 2000~ | `2000.1` … | `2` … `12` | 문자(일부 구간 숫자 혼재) |

- 행마다 날짜를 해석하면 `86.1`(숫자)과 `"2000.1"`(문자)이 섞여 오류가 나기 쉽다. 1986-01부터 행 순서로 월 수열을 만들고, 1월 표기를 검산용으로만 쓴다.
- A열을 문자로 읽으면 숫자 셀 `86.1`도 문자 `"86.1"`로 들어온다. 1월 판별은 소수점 뒤가 `1`이고 앞이 두 자리 또는 네 자리 숫자인지로 한다.
- 2026.10 발표본의 자료 행은 490개(1986.01~2026.10)다.

## 발표본마다 바뀌는 열

새 행정구역이 생기면 열이 중간에 추가된다. 2026년 발표본에서 추가된 예는 다음과 같다.

- 인천광역시 아래 `제물포구`, `영종구`, `서해구`, `검단구`
- 화성시 아래 `만세구`, `효행구`, `병점구`, `동탄구`
- `전남광주\n통합특별시` 열과, 기존 광역시 계열을 담는 `(구)광주광역시` 열

이 때문에 열 번호는 발표본 사이에 보존되지 않는다. 지역은 항상 이름으로 찾는다.

## 이름이 겹치는 지역

| 겹치는 이름 | 구별 방법 |
| --- | --- |
| 중구·서구·남구·북구·동구·강서구 | 상위 지역과 함께 `부산광역시>중구`처럼 식별 |
| 경기 `광주시` vs `(구)광주광역시` | 광역시 장기 계열은 `(구)광주광역시` |
| `제주/\n서귀포` vs `제주특별자치도` | 사용 전에 두 열의 시작월과 값을 확인 |

## 시작월 확인 방법

열마다 첫 숫자 값이 나오는 행으로 시작월을 구한다. 2026.10 발표본의 결과는 [지역 대응표](region-map.md)에 정리되어 있다. 새 발표본에서 시작월이 대응표와 다르면 멈추고 보고한다.
